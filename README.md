##  Problem Statement

Managing daily expenses manually is inefficient and error-prone. Users often struggle to track their spending patterns and analyze financial behavior.

There is a need for a simple desktop-based application that allows users to securely record, manage, and analyze expenses.

---

##  Objective

To develop a Java Swing-based Expense Management System that:

- Provides secure user authentication
- Allows adding, updating, and deleting expenses
- Displays expense analysis using graphical representation
- Stores user data securely in a database
- Supports multi-user functionality

---

## Features

- User Login System
- Add Expense
- Update / Delete Expense
- Expense Table View
- Graphical Analysis (Bar Chart)
- Session-based Data Filtering
- Custom UI with Rounded Components
- Database Integration using JDBC

---

## Technologies Used

- Java (Swing)
- SQLite
- JDBC
- Object-Oriented Programming
- Event Handling
- Layout Managers (BorderLayout, GridLayout, FlowLayout, CardLayout)

---

##  How to Run

1. Open the project in NetBeans.
2. Ensure SQLite JDBC driver is added.
3. Run DailyDimeApp.java.
4. Login and start managing expenses.
